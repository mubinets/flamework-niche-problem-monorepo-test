# Compilation
Run ``root:start`` to compile AND rojo serve so you can test immediately.
Run ``root:once`` to compile once without starting rojo serving.
Run ``root:serve`` to just start rojo serving.
Run ``root:watch`` to compile and begin watching for incremental compilation.

Tip: ``root`` means a name of specific project like ``projects/root/`` for compilation, you could add additional projects and create new scripts to run like ``place2:watch``, ``places2:once``, etc.
